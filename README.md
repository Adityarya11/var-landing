# var-landing

Landing page for Voice Agent Runtime: https://github.com/Adityarya11/voice-agent-runtime

Next.js (App Router), Tailwind CSS v4, light theme only. No backend, no environment variables.

## Run

```
npm install
npm run dev
npm run build
```

## Structure

- `src/app/page.tsx` renders the sections in order: Hero, Numbers, Architecture, VideoSection, Limits, Writing, Footer.
- `src/lib/links.ts` holds every external URL.
- `src/app/globals.css` holds the color tokens under `@theme inline`. There is no Tailwind config file.

## Numbers

Every figure on the page comes from `docs/benchmarks.md` in the voice-agent-runtime repository, which is generated by the scripts in `scripts/bench/`. Update `src/components/Numbers.tsx` from that report, and keep its caveats next to the figures.
